# Веб-инструкция MemoList

Файл [`instructions.html`](instructions.html) — пользовательская инструкция для версии **3.13.2**.

## Публикация

1. Загрузите `instructions.html` на публичный веб-ресурс (Яндекс.Диск, GitHub Pages, свой хостинг).
2. Получите прямую HTTPS-ссылку на файл.
3. Укажите её в `gradle.properties`:

```properties
memolist.instructionsUrl=https://ваш-хост/instructions.html
```

4. Пересоберите приложение — пункт «Инструкция» в меню откроет эту ссылку в браузере.

Язык страницы: параметр `?lang=ru` или `?lang=en` (приложение подставляет язык системы автоматически).

## Обновление текста

Редактируйте только `instructions.html`. Строка `instructions_text` в приложении удалена.
