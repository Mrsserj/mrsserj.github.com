MemoList

3.13.2

Шпаргалка

  1. Иконка списка слева — «Мои списки».
  2. «+» внизу — новый пункт.
  3. Чекбокс: [ ] → [~] → [✓] (если статусы включены).
  4. Свайп вправо — удалить, влево — архив (только корневые пункты).
  5. Панель списка: фильтр, сортировка, метла (сброс галочек), настройки.

Мои списки

  • Карточки списков; кольцо прогресса % скрыто, если в списке «Статусы = 0» (данные не стираются).
  • Свайп влево по списку — в архив; вправо — удаление с задержкой.
  • Секция «Архив» внизу — тап по всей строке сворачивает/разворачивает.
  • При первой установке добавляются примеры списков.

Пункты и статусы

Меню → Действия → «Статусы»:

  • 0 — без чекбоксов и без индикатора прогресса.
  • 2 — пусто / готово.
  • 3 — пусто / в работе / готово (по умолчанию).

Чекбокс меняет состояние по кругу. У родителя с активными детьми чекбокс приглушён — статус считается по подпунктам.

Фильтр и новый список

  • Воронка в панели списка — фильтр по #тегам, цветовым меткам и статусам.
  • При активном фильтре можно создать новый список только из видимых пунктов.
  • Сортировка сбрасывается при перемещении пунктов.

Сброс всех галочек (метла)

  • Иконка метлы слева от шестерёнки, если есть отмеченные пункты и фильтр выключен.
  • Сбрасывает все активные пункты всех уровней; подтверждение: «Будут сброшены все галочки».

Архив пунктов

  • В архив отправляется только корневой пункт; подпункты архивируются вместе с ним.
  • Свайп влево по подпункту для архива недоступен.
  • В архиве: свайп влево — восстановить, вправо — удалить.
  • Тап по строке «Архив» — свернуть/развернуть (в списке и на экране «Мои списки»).

Подпункты

  • «Подпункт» в редактировании; сворачивание группы стрелкой.
  • Глубина — в меню списка или в общих настройках.

Метки и теги

Цветовые метки (1…N)

Действия → «Корзины»; назначение в редактировании пункта.

#Теги

В тексте или Действия → «Теги». Переименование меняет имя и цвет в словаре и в пунктах.

Вставка списка из текста

  • «Новый список» → «Развернуть для вставки списка».
  • Первая строка — название, далее пункты; отступы — подпункты.
  • Номера: «1. Текст», «9.1 Текст» (точка после подномера необязательна).
  • Пропуски в нумерации выравниваются по порядку строк.
  • «Поделиться» текстом из другого приложения открывает диалог создания списка.

Шаблоны

  • Действия → «Сохранить как шаблон» / «Добавить из шаблона».
  • Шаблоны в меню «Шаблоны»; в шаблоне нет чекбоксов и архива пунктов.

Обмен списком

  1. Самолётик в шапке — обычный нумерованный текст (без архивных пунктов).
  2. Действия → «Поделиться в MemoList» — внутренний формат для импорта.
  3. Действия → «Выгрузить файл .memolist».

Меню приложения

Тема, плотность, глубина подпунктов, шаблоны, инструкция, облачная копия.

Облачная копия

Файл Documents/MemoList/memolist-backup.json — сохранение, отправка и восстановление данных.

Quick cheatsheet

  1. List icon (top left) — My lists.
  2. “+” at bottom — new item.
  3. Checkbox: [ ] → [~] → [✓] (when statuses are enabled).
  4. Swipe right — delete, left — archive (root items only).
  5. List toolbar: filter, sort, broom (reset checkmarks), settings.

My lists

  • List cards; progress ring is hidden when “Statuses = 0” (data is kept).
  • Swipe left on a list — archive; right — delayed delete.
  • “Archive” section at the bottom — tap the row to expand/collapse.
  • Sample lists are added on first install.

Items and statuses

Menu → Actions → “Statuses”:

  • 0 — no checkboxes and no progress indicator.
  • 2 — empty / done.
  • 3 — empty / in progress / done (default).

Checkbox cycles states. A parent with active children has a dimmed checkbox — status is derived from children.

Filter and new list

  • Funnel in the list toolbar — filter by #tags, color marks, and statuses.
  • With an active filter you can create a new list from visible items only.
  • Sort is cleared when you move items.

Reset all checkmarks (broom)

  • Broom icon left of the gear when any item is marked and the filter is off.
  • Resets all active items at every level; confirm: “All checkmarks will be cleared.”

Item archive

  • Only root items can be archived; sub-items go with the parent.
  • Swipe-to-archive is disabled for sub-items.
  • In archive: swipe left — restore, right — delete.
  • Tap the “Archive” row to expand/collapse (in a list and on My lists).

Sub-items

  • “Sub-item” in edit dialog; collapse groups with the arrow.
  • Depth — per list in Actions or global in Help menu.

Marks and tags

Color marks (1…N)

Actions → “Bins”; assign in item edit.

#Tags

In text or Actions → “Tags”. Rename updates name and color in the vocabulary and in items.

Paste list from text

  • “New list” → “Expand to paste list”.
  • First line — title, then items; indent — sub-items.
  • Numbers: “1. Text”, “9.1 Text” (trailing dot after sub-number is optional).
  • Gaps in numbering are normalized to document order.
  • Share text from another app opens the new-list dialog.

Templates

  • Actions → “Save as template” / “Add from template”.
  • Templates in Help → Templates; no checkboxes or item archive in templates.

Sharing

  1. Paper plane in the top bar — plain numbered text (no archived items).
  2. Actions → “Share in MemoList” — internal format for import.
  3. Actions → “Export .memolist file”.

Help menu

Theme, density, sub-item depth, templates, instructions, cloud backup.

Cloud backup

File Documents/MemoList/memolist-backup.json — save, share, and restore data.
