MemoList

3.16.6

Шпаргалка

  1. arrow_back слева на экране списка — «Мои списки».
  2. add внизу — новый пункт; при вводе могут появляться подсказки из словаря.
  3. Чекбокс: check_box_outline_blank → в работе → check_box (если статусы включены).
  4. Свайп влево — archive архив (только корневые). Свайп вправо — delete удаление: обычный режим — ~5 с ожидания; двойной — два свайпа вправо.
  5. Панель: filter_alt фильтр, sort сортировка, cleaning_services метла, settings настройки.
  6. more_vert или settings — «Помощь»; на экране списка — «Действия».

Мои списки

  • Карточки списков; кольцо прогресса % скрыто, если «Статусы = 0» (отметки не стираются).
  • Свайп влево — archive в архив; вправо — delete удаление (~5 с), влево отменяет.
  • Секция «Архив» внизу — тап сворачивает/разворачивает (keyboard_arrow_down / keyboard_arrow_up).
  • При первой установке добавляются примеры списков.

Новый список

Кнопка «Новый» на экране «Мои списки» или в меню. Можно сразу ввести только название или развернуть дополнительные блоки.

Вставка из текста

  • «Развернуть для вставки списка» — первая строка название, далее пункты; отступы задают подпункты.
  • Номера «1. Текст», «9.1 Текст» (точка после подномера необязательна); пропуски в нумерации выравниваются.
  • share «Поделиться» текстом из другого приложения открывает этот же диалог.

Параметры

expand_more Раздел «Параметры» задаёт поведение создаваемого списка:

  • account_tree Глубина подпунктов — уровни вложенности (0 — без подпунктов); remove / add.
  • checklist Статусы — 0 (без чекбоксов), 2 (пусто/готово), 3 (пусто/в работе/готово).
  • palette Корзины — число цветовых меток (1…N) в редактировании пункта.
  • swipe_right Двойной свайп для удаления — см. раздел ниже.
  • Для всех новых — умолчания для следующих новых списков (существующие не меняются).

Пункты и статусы

Меню → Действия → checklist «Статусы» (или в «Параметрах» нового списка):

  • 0 — без check_box и без индикатора прогресса.
  • 2 — check_box_outline_blank / check_box.
  • 3 — пусто / в работе / готово (по умолчанию).

Чекбокс меняет состояние по кругу. У родителя с активными детьми чекбокс приглушён. При «готово» родитель с детьми может свернуться (keyboard_arrow_up).

Фильтр

  • filter_alt Воронка в панели списка — фильтр по sell #тегам, palette меткам и статусам.
  • Можно выбрать несколько условий; видны только подходящие пункты.
  • При активном фильтре — note_add «Создать список из фильтра».
  • С фильтром при добавлении дубликат по названию не создаётся — теги дописываются к существующей строке.
  • sort Сортировка сбрасывается при ручном перемещении пунктов.
  • При повороте экрана фильтр сохраняется.

Подсказки при вводе

«Помощь» → tips_and_updates «Использовать подсказки при вводе» — общий переключатель.

  • При первом включении словарь наполняется автоматически; сообщение «Словарь подсказок обновлён».
  • При add добавлении пункта появляются подсказки; выбор подставляет название.
  • Словарь общий; только названия — без #тегов и меток.
  • Частота растёт при отметке check_box «готово».
  • С filter_alt фильтром подсказки из списка и словаря.
  • При совпадении названия — предупреждение о дубликате.
  • В edit редактировании подсказки не показываются.
  • При выключении словарь очищается.

Удаление свайпом

Обычный режим (по умолчанию)

  • Свайп вправо — delete красное зачёркивание; через ~5 с удаление.
  • Свайп влево — restore отмена до истечения времени.

Двойной свайп

Включается в Действия → swipe_right «Двойной свайп для удаления» или в «Параметрах» нового списка.

  • Первый свайп вправо — серая пометка (delete).
  • Второй свайп вправо — удаление сразу.
  • Пока помечен — нельзя edit редактировать и менять check_box статус.
  • Свайп влево снимает пометку.

archive Архив — свайп влево по корневому пункту. Подсказка внизу списка зависит от режима.

Сброс всех галочек (метла)

  • cleaning_services слева от settings шестерёнки, если есть отмеченные пункты и filter_alt фильтр выключен.
  • Сбрасывает все активные пункты в «пусто»; нужно подтверждение.
  • При включённом фильтре метла скрыта.

Архив пунктов

  • В архив — только корневой пункт; подпункты уходят вместе с ним.
  • archive Свайп влево по подпункту недоступен.
  • В архиве: влево — restore восстановить; вправо — delete удалить.
  • Недавно архивированные — выше в списке.
  • Строка «Архив» — keyboard_arrow_down / keyboard_arrow_up свернуть/развернуть.

Подпункты

  • subdirectory_arrow_right «Подпункт» при редактировании; keyboard_arrow_up / keyboard_arrow_down сворачивание группы.
  • account_tree Глубина — в Действиях или в «Помощь».
  • Меню more_vert: arrow_upward / arrow_downward, south_east подпунктом вышестоящего, north_west поднять уровень.

Метки и теги

Цветовые метки (1…N)

Действия → palette «Корзины»; назначение в редактировании пункта.

#Теги

В тексте (#тег) или Действия → sell «Теги»:

  • Строка «Теги» с add; в полном списке — edit и close.
  • Редактирование в той же панели меню; arrow_back возврат к списку тегов.
  • Переименование и объединение тегов обновляет все пункты.

Шаблоны

«Помощь» → description «Шаблоны». Без чекбоксов, filter_alt, sort и mic.

  • Открыть шаблон — редактировать пункты как в списке.
  • note_add «Создать список» — новый список вверху «Мои списки».
  • Вправо — delete; влево — archive в архив шаблонов.
  • Действия → bookmark_add «Сохранить как шаблон».
  • Действия → note_add «Добавить из шаблона» — блоком или только пункты.
  • Дубликаты при добавлении не создаются.

Слияние списков

Действия → merge_type «Слить из другого списка». Архивные источники не предлагаются.

Способ вставки

  • Блоком — под заголовком с названием источника;
  • Только пункты — корневые строки.

Параметры

  • delete Удалить исходный список.
  • palette Сохранить метки.
  • sell Сохранить теги.
  • checklist Сохранить статусы.

После слияния — статистика добавленных и совпавших пунктов.

Голосовой ввод

  • mic на экране списка — диктовка; «Готово» добавляет пакетом.
  • На «Мои списки» mic → «Новый список» с текстом.
  • В диалоге вставки mic дописывает в поле.
  • На «Шаблоны» микрофона нет.

Обмен списком

  1. send в шапке — нумерованный текст (без архива).
  2. Действия → share «Поделиться в MemoList» — формат импорта.
  3. Действия → description «Выгрузить .memolist».

Повторный импорт объединяет по идентификаторам.

Альбомная ориентация

  • Слева — вертикальное название (тап — переименовать); справа — панель действий.

На экране списка — блок «Действия» (см. ниже).

Действия со списком

На экране списка: панель над пунктами и меню «Помощь» (settings в панели или more_vert в шапке) → раздел «Действия».

Панель над списком

filter_alt фильтр sort сортировка по возрастанию по убыванию cleaning_services метла settings настройки
  • filter_alt Фильтр — воронка слева; открывает панель отбора по #тегам, цветовым меткам и статусам.
  • sort Сортировка — без активной сортировки. После выбора критерия иконка меняется на стрелку вверх или вниз (как в приложении).
  • cleaning_services Метла — сброс всех галочек; видна только если есть отмеченные пункты и фильтр выключен.
  • settings Настройки — открывает меню «Помощь» с блоком «Действия» для этого списка.

Шапка списка

  • send Отправить (самолётик) — поделиться списком обычным текстом без архивных пунктов.
  • mic Микрофон — голосовой ввод пунктов (на экране шаблонов недоступен).

Раздел «Действия» в меню

  • send Отправить — те же варианты обмена, что и в шапке, плюс форматы MemoList.
  • account_tree Глубина подпунктов — кнопки remove / add; для этого списка или наследование общей настройки.
  • checklist Статусы — режим 0 / 2 / 3; переключение remove / add.
  • palette Корзины — число цветовых меток; remove / add.
  • swipe_right Двойной свайп для удаления — переключатель режима удаления свайпом вправо.
  • sell Теги — словарь #тегов; add для добавления; в списке всех тегов — edit и close.
  • note_add Добавить из шаблона — вставка блоком или только пунктами.
  • bookmark_add Сохранить как шаблон — заготовка из текущего списка.
  • merge_type Слить из другого списка — перенос пунктов с параметрами слияния.

Свайпы по пункту

  • archive Свайп влево (корневой пункт) — в архив; при перетаскивании видна иконка архива.
  • delete Свайп вправо — удаление; при перетаскивании видна корзина.
  • restore В архиве свайп влево — восстановить; у зачёркнутого пункта свайп влево — отменить удаление.

Иконки на этой странице соответствуют набору Material Icons в приложении; сортировка по возрастанию/убыванию — те же рисунки, что в ic_sort_asc / ic_sort_desc.

Облачная копия

cloud_upload Файл Documents/MemoList/memolist-backup.json на устройстве.

  • save «Сохранить копию сейчас».
  • share «Поделиться файлом бэкапа».
  • cloud_download «Восстановить из облака» — локальный файл и/или Google Диск.
  • Автосохранение при сворачивании — в настройках бэкапа.

При первом запуске, если найден бэкап, предлагается восстановление.

Quick cheatsheet

  1. arrow_back on a list screen — My lists.
  2. add at bottom — new item; suggestions may appear while typing.
  3. Checkbox: check_box_outline_blank → in progress → check_box (when statuses enabled).
  4. Swipe left — archive archive (roots only). Swipe right — delete delete: single ~5 s wait; double — two right swipes.
  5. Toolbar: filter_alt filter, sort sort, cleaning_services broom, settings settings.
  6. more_vert or settings — Help; on a list — Actions.

My lists

  • List cards; progress ring hidden when “Statuses = 0”.
  • Swipe left — archive archive; right — delete delete (~5 s), left undoes.
  • “Archive” row — keyboard_arrow_down / keyboard_arrow_up expand/collapse.
  • Sample lists on first install.

New list

“New” on My lists or in the menu. Title only, or expand optional blocks.

Paste from text

  • “Expand to paste list” — title, then items; indent for sub-items.
  • Numbers “1. Text”, “9.1 Text”; gaps normalized.
  • share Share text from another app opens this dialog.

Parameters

expand_more “Parameters” for the new list:

  • account_tree Sub-item depth; remove / add.
  • checklist Statuses — 0 / 2 / 3.
  • palette Bins — color marks count.
  • swipe_right Double swipe to delete — see below.
  • For all new — defaults for future lists only.

Items and statuses

Menu → Actions → checklist “Statuses”:

  • 0 — no check_box or progress ring.
  • 2 — check_box_outline_blank / check_box.
  • 3 — empty / in progress / done (default).

Checkbox cycles states. Dimmed parent checkbox when children are active. Done children may collapse parent (keyboard_arrow_up).

Filter

  • filter_alt Funnel — sell #tags, palette marks, statuses.
  • Multiple conditions can be combined.
  • Active filter — note_add create list from visible items.
  • Adding with filter on merges tags onto existing title — no duplicate row.
  • sort Sort clears when you move items.
  • Filter kept on rotation.

Input suggestions

Help → tips_and_updates “Use input suggestions”.

  • First enable fills dictionary automatically.
  • add While adding, suggestions appear; tap to insert.
  • Shared dictionary; plain titles only.
  • Frequency grows on check_box done.
  • With filter_alt filter — list + dictionary matches.
  • Duplicate title warning possible.
  • Not shown in edit edit dialog.
  • Disable clears dictionary.

Swipe to delete

Single mode (default)

  • Swipe right — delete red strikethrough; ~5 s then removed.
  • Swipe left — restore undo before timeout.

Double swipe

Actions → swipe_right “Double swipe to delete”, or in Parameters.

  • First right swipe — gray mark (delete).
  • Second right swipe — delete immediately.
  • While marked — no edit or check_box.
  • Swipe left clears mark.

archive Archive — swipe left on root items. Bottom hint reflects mode.

Reset all checkmarks (broom)

  • cleaning_services left of settings when items marked and filter_alt filter off.
  • Resets all active items to empty; confirmation required.
  • Hidden while filter active.

Item archive

  • Root items only; sub-items go with parent.
  • archive No archive swipe on sub-items.
  • In archive: left — restore; right — delete.
  • Recently archived first.
  • “Archive” row — keyboard_arrow_down / keyboard_arrow_up.

Sub-items

  • subdirectory_arrow_right “Sub-item” in edit; keyboard_arrow_up / keyboard_arrow_down collapse.
  • account_tree Depth — Actions or Help.
  • more_vert menu: arrow_upward / arrow_downward, south_east, north_west.

#Tags

Templates

Merge lists

Insert mode

  • As block — under source title parent;
  • Items only — root rows.

List actions

On a list screen: the toolbar above items and Help menu (settings in the toolbar or more_vert in the top bar) → Actions section.

List toolbar

filter_alt filter sort sort ascending descending cleaning_services broom settings settings
  • filter_alt Filter — funnel on the left; opens tag, color mark, and status filters.
  • sort Sort — default icon when no sort is active. After choosing a criterion, the app shows the ascending or descending arrow icons.
  • cleaning_services Broom — reset all checkmarks; shown only when items are marked and the filter is off.

Top bar

  • send Send (paper plane) — share the list as plain text without archived items.
  • mic Microphone — voice input for items (not on Templates screen).

Actions section in the menu

  • send Send — same sharing options as the top bar, plus MemoList formats.
  • account_tree Sub-item depth — remove / add stepper; per list or inherit global setting.
  • checklist Statuses — mode 0 / 2 / 3; remove / add.
  • palette Bins — number of color marks; remove / add.
  • swipe_right Double swipe to delete — toggle for swipe-right delete mode.
  • sell Tags — #tag vocabulary; add to add; in the full list — edit and close.
  • note_add Add from template — insert as block or items only.
  • bookmark_add Save as template — preset from the current list.
  • merge_type Merge from another list — copy items with merge options.

Item swipes

  • archive Swipe left (root item) — archive; archive icon while dragging.
  • delete Swipe right — delete; trash icon while dragging.
